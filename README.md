# apex-context (retired)

This project's log report and "done without proof" hook are retired: our own experiment (Gemini CLI, 12 tasks, 120 runs) found no measurable effect, and the write-up is in [docs/EXPERIMENTS.md](https://github.com/apex-context-dev/apex-engine/blob/main/docs/EXPERIMENTS.md).

The benchmark harness lives on as **apex-bench**, and everything else moved to **[Apex Engine](https://github.com/apex-context-dev/apex-engine)**: an open engine that makes any model a reliable coder, with a public, reproducible leaderboard.

- Engine: `npm i apex-engine-core` · CLI: `npx apex-agent` · Benchmark: `npx apex-bench`
- The last published version, `apex-context@0.2.0`, stays installable but is deprecated.

This repository is archived.
