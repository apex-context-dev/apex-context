# Support

- **Questions and how-to:** open a GitHub issue using the feature request template or a discussion if enabled. Check the [README](README.md), `apex-context --help`, and `report --explain` / `gate --explain` first.
- **Bugs:** open an issue with the bug report template. Include `apex-context --version`, your Node version, the command and a synthetic reproduction.
- **Adapter requests:** use the adapter request template.
- **Security and privacy problems:** do not open a public issue; see [SECURITY.md](SECURITY.md).
- **Conduct concerns:** see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Please never attach real session logs, transcripts, prompts or file paths from your projects. Synthetic examples only.

This is a volunteer-maintained open project; there is no service-level promise.
